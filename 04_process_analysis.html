Process Analysis (Including Statistical Analysis)

High‑Level Process Map

For a typical inbound call, the process is:

  1. Customer dials support number.
  2. IVR routes call to an available agent.
  3. Agent greets customer and verifies identity.
  4. Agent listens and identifies the main request.
  5. Agent researches the answer (systems, knowledge base, colleagues).
  6. Agent resolves the issue or transfers to another queue if needed.
  7. Agent summarizes next steps and closes the call.
  8. Agent completes wrap‑up notes.

Time Study

A small time study was done on 50 calls. Average times per step:

Step Average Time (minutes)
Greeting and verification 1.5
Understanding the request 1.0
Research / Resolve (no transfer) 3.0
Research / Resolve (with transfer) 7.0
Wrap‑up 1.0

Basic Statistical Comparison

Two simple groups were compared:

  • Group A: Calls without a transfer (n = 30), mean AHT ≈ 6.5 minutes.
  • Group B: Calls with at least one transfer (n = 20), mean AHT ≈ 10.5 minutes.

Even without heavy statistics, a 4‑minute average gap is large in this business context and clearly meaningful. In a more formal setting, a simple two‑sample t‑test could be used, but for this classroom project the effect size alone already shows that transfers are a major driver of AHT. [web:594][web:596]

Process Weak Spots Highlighted

  • The process has no clear decision rule on when to transfer versus when to own a case.
  • Research steps are longer when agents use multiple systems instead of a single view.
  • Wrap‑up time is small, so it is not the main driver of AHT.
