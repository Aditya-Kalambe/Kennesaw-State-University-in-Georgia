Summary of Next Steps

Focus Areas Chosen

  • Reduce research time by improving the knowledge base.
  • Reduce unnecessary transfers, especially for billing and refunds.
  • Remove obvious waste (double documentation, screen hopping).

Planned Actions for Improve Phase

  1. Knowledge Base Quick Fix Pilot (2–3 weeks)
    • Clean up and re‑label the top 20 articles used for billing and refunds.
    • Add a simple “favorites” list for these articles in the agent toolbar.
    • Run a pilot with 5 volunteer agents and compare AHT before/after.
  2. Clarify Transfer Rules (1–2 weeks)
    • Agree simple rules: which billing questions front‑line agents must own, and which can be transferred.
    • Update training slides and run a 1‑hour refresher session.
  3. Reduce Documentation Waste (2 weeks)
    • Create a short “smart template” for notes, shared across teams.
    • Remove duplicate fields in the second system or auto‑fill them.

Measures of Success

  • Reduce AHT for billing and refund calls from 11 minutes to 9 minutes within 2 months.
  • Reduce the percentage of calls with a transfer by 20% in the pilot group.
  • Keep customer satisfaction scores at or above current levels.

Control Phase Ideas (Early View)

  • Add a simple weekly dashboard for AHT by call type and by team.
  • Review 10 calls per week to check adherence to the new call flow.
  • Schedule quarterly knowledge base reviews so content does not slip again.

Link Back to Analyze Phase

Every planned action directly addresses a cause that was highlighted by one or more Analyze‑phase tools:

  • Knowledge base cleanup → high‑RPN FMEA item and long research time.
  • Transfer rules → Cause & Effect and the large AHT gap for transferred calls.
  • Template simplification → 8 wastes (overprocessing, motion) and COPQ time loss.

This clear thread from data → cause → action keeps the project focused and makes it easier for peers and instructors to see that the DMAIC logic is being followed. [web:594][web:596][web:601]
