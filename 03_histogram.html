Histogram and Graphical Analysis

Data Used

We took a simple sample of 100 calls from the last two weeks and recorded the Average Handle Time (AHT) for each call in minutes.

Histogram Description

Instead of plotting the actual chart here, this document describes it in words so it is easy to recreate in Excel:

  • 0–4 minutes: 5 calls
  • 4–6 minutes: 20 calls
  • 6–8 minutes: 35 calls
  • 8–10 minutes: 25 calls
  • 10–12 minutes: 10 calls
  • 12–20 minutes: 5 calls

This shape looks roughly like a peak around 6–8 minutes with a smaller “tail” of very long calls up to 20 minutes. Histograms are standard tools in Six Sigma to show how data is distributed and to make long‑tail issues visible. [web:598][web:605]

Box Plot Description

A simple box plot of AHT by call type (general, billing, refund, technical) shows higher medians and more spread for billing and refund calls. This supports the idea that these call types deserve special focus in the Improve phase.

Key Insights

  • Most calls finish in under 10 minutes, so not every part of the process is broken.
  • A small number of very long calls have a big impact on the average.
  • Billing and refund calls have clearly higher AHT and more variability.

In the Analyze phase, graphs like histograms and box plots help translate raw data into simple pictures that everyone on the team can understand. [web:598][web:605]
